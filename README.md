# Ромашка

Учебный магазин: каталог, корзина, промокоды, доставка и история заказов.
Python 3.11 или новее. Библиотеки извне не требуются.

## Запуск тестов

Из корня репозитория:

```bash
python -m unittest discover -s tests -v
```

Используется стандартный unittest, устанавливать pytest не нужно.

## Модули

| Модуль | Назначение |
|---|---|
| `shop/catalog.py` | `PRODUCTS`: артикул → (название, цена в копейках, категория); `search(query)` → артикулы |
| `shop/money.py` | `apply_discount(amount, percent)` → сумма после скидки в копейках |
| `shop/cart.py` | `Cart`: `add(sku, quantity=1)`, `remove(sku)`, `apply_promo(code)`, `goods_total()`, `delivery()`, `total()` |
| `shop/delivery.py` | `ship_date(ordered_at)` → дата отправки |
| `shop/orders.py` | `sort_orders(orders)` → новый список заказов от новых к старым |

## Правила магазина

- Цены и результаты расчётов — целые копейки. Скидка округляется до ближайшей копейки, половина — вверх. Процент от 0 до 100, сумма неотрицательная.
- SAVE10 и SAVE15 дают скидку 10% и 15%. Регистр и пробелы по краям промокода не важны. Неизвестный код отклоняется.
- Доставка стоит 299 ₽, бесплатна от 3000 ₽ включительно после скидки. Для пустой корзины — 0.
- Склад работает по будням. Заказ до 14:00 отправляется в тот же рабочий день, начиная с 14:00 — в следующий. Выходные пропускаются. Государственные праздники не учитываются.
- В истории даты имеют формат ДД.ММ.ГГГГ. Новые заказы показываются первыми; входной список не меняется.
- Поиск ищет подстроку названия без учёта регистра и различия е/ё.
- Оплата частями пока не реализована.

Существующие тесты проверяют базовые сценарии. При исправлении добавляйте регрессионные тесты в новые `tests/test_*.py`, не меняя существующие тесты.
